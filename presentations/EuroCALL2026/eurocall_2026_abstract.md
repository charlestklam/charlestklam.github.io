# Title 
Visualizing the DNA of discourse: sequence of rhetorical moves and steps in Python

# Abstract 
Novice and L2 writers often struggle to replicate rhetorical structures of academic writing, which are often discipline- and genre-specific. While they have general notions like ‘providing the background,’ they often fail to see the underlying organisational patterns that facilitate readers’ understanding. This project addresses the challenge through visualizing rhetorical move-step analysis (Swales, 2004; Cotos et al., 2017), inspired by another MSA: Multiple Sequence Alignment, a biology method to identify regions in DNA sequences. 

This presentation introduces MoveStepViz, a Python library and accompanying web application designed to generate ‘DNA-strip’ visualizations of rhetorical structure. Annotated text sequences (e.g. the label ‘M1S3’ for reviewing previous research) are represented in colour-coded boxes with labels, the tool then renders an image with horizontal sequences of rhetorical moves and steps to visualize the progression of discourse. The accompanying web application features a small reference corpus with move-step analysis of academic articles, visually representing the progression between rhetorical moves. It also allows users to upload custom data and generate visualizations without coding, enabling side-by-side comparison of multiple text segments. 

This biology-inspired visualization supports genre learning by making rhetorical progression visible and intuitive. This also facilitates linguistic inclusion by decoding opaque academic norms for novice and L2 writers. Presenting structure and sequence visually is a tool already familiar to students in many disciplines. The presentation will demonstrate how this cross-disciplinary metaphor transforms abstract linguistic notion of genre into a tangible, data-driven learning instrument. The tool and its development process exemplify a novel workflow for the AI era: The author’s domain expertise in linguistics defines the pedagogical goals and design requirements, while GenAI agents accelerate the implementation. This demonstrates how the technical threshold is lowered to allow linguists to engineer and fine-tune their bespoke, discipline-specific tools for niche problems.
